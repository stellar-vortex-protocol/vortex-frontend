# State of the Protocol — 2026 Q3

> Period: 2026-07-01 – 2026-09-30. Data as of 2026-09-26, so the quarter's last
> days aren't included. Compiled from this repository's GitHub history; see
> [TEMPLATE.md](./TEMPLATE.md) for the format.

## Summary

Q3 took the Vortex frontend from its first components to a feature-complete
swap UI and solver portal: 122 PRs from 67 authors, most of them through the
Drips Wave contributor program. There is no public protocol activity to report
yet, because the relay isn't deployed publicly. The quarter ends with `main` not
compiling after the 1 September merge wave; repairs are tracked in #397, #398
and #399.

## Protocol activity

**No data this quarter.** The [`/analytics`](../../src/app/analytics/AnalyticsPageClient.tsx)
view (shipped in #350) computes volume, fills and solver activity client-side
from the relay's last 200 tracked intents, but no public `vortex-backend` relay
was running during the quarter, so there are no intents to report. The first
report with a live relay should fill the metrics table from that view and state
its 200-intent window.

## Notable shipped changes

`CHANGELOG.md` still only has its initial entries (see *Health and known
issues*), so this list is compiled from merged PRs.

**Foundations (13–14 July)**
- **Wallet** — Freighter connect/disconnect, a Zustand wallet store and
  persisted sessions with auto-reconnect (#3, #4, #5)
- **Swapping** — API client and SWR hooks, live quotes in SwapCard, and
  end-to-end swap submission signed in Freighter (#6, #7, #10)
- **Explorer and solvers** — `/explore` with live updates and pagination, the
  intent detail page, the solver leaderboard, the open-intents tab with Accept
  Intent, and solver registration (#13–#18)
- **Platform** — Vitest + Testing Library in CI, shared Nav/Footer, toasts and
  an accessibility pass (#1, #2, #19, #22)

**Features, i18n and quality (28–30 July)**
- **My Intents** — a per-wallet swap history with filters and empty states
  (#150–#153, #173, #176)
- **Localisation** — strings externalised across the app, locale-aware number
  and currency formatting, and a locale switcher (#154–#156, #159, #161, #162, #170)
- **Swap safety** — stale-quote guard, a specific no-solver error, destination
  address validation, token decimal precision and duplicate-submit prevention
  (#191, #195–#197, #201)
- **Accessibility** — reduced-motion support, contrast fixes and several a11y
  audits (#172, #177, #179, #181, #193)
- **Tooling and docs** — commitlint/husky, pinned Node, a Playwright smoke test,
  issue/PR templates, and testing and WebSocket protocol docs (#178, #185,
  #190, #199, #200, #206, #207)

**Security, community and DevOps (1–2 September)**
- **Security hardening** — client-side XDR review before signing and signed-XDR
  verification, homoglyph/bidi address spoofing defences, and a published
  security policy (#357, #366, #370, #372, #373)
- **Community** — the analytics view (#350), a contributors page for Drips Wave
  contributors (#375), and governance comments with solver onboarding (#379)
- **Swap UX** — slippage control, stale-quote refresh, quote deltas, a command
  palette, QR codes and a progress stepper (#362, #365, #367, #380)
- **Wallet** — adapter abstraction, multi-tab session sync and live network
  mismatch detection (#353, #368, #380)
- **CI/DevOps** — i18n catalog parity check, documentation link checking, CI
  badges, an uptime monitor, editorconfig checks, strict TypeScript and a
  staging environment (#349, #374, #376, #378)

## Health and known issues

- **`main` doesn't build.** The 1 September merge wave was merged branch by
  branch, and the overlaps left duplicated declarations, dropped imports and
  lost features. `tsc --noEmit` stopped at syntax errors, and several test
  suites couldn't be collected. Repairs are tracked in #397 (wallet store),
  #398 (swap path) and #399 (app shell and pages); #401
  covers the remaining type errors.
- **`package-lock.json` is out of sync** with `package.json`, so `npm ci` fails.
- **The i18n parity check fails** because 27 keys in `en.ts` have no `es.ts`
  translation.
- **Data caveats:** `CHANGELOG.md` has not been updated since its initial entry,
  and its `0.1.0` heading is dated 2025-07-30, before this repository's first
  commit (2026-06-19). No PRs were merged in August, so August's work only
  shows up in the September counts.
